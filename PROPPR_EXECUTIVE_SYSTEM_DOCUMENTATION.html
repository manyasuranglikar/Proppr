Direct Answers to the 5 Core Questions

1. Which leads are duplicates, and why?
Lead 101 and Lead 103 are duplicates. Both share the exact same phone number (9876543210) and name (Rahul Sharma). Lead 101 came from the Website; Lead 103 came from an Advertisement.
2. How do we ensure duplicate enquiries do not create unnecessary CRM records?
Search-Before-Insert: Before creating a contact, the system searches the CRM by phone number. Because Rahul Sharma exists from Lead #101, it skips creating a new contact and appends a touchpoint note ("Repeat enquiry from Advertisement") to his existing profile.
3. How do we flag Gurgaon leads with budget ≥ ₹1.5 Cr for priority?
The system converts budget text to numbers (₹1.5 Cr ➔ 15,000,000). When Location == 'Gurgaon' and Budget >= 15,000,000, it flags Leads 101 and 104 as VIP, sets a 15-minute SLA, routes to the Senior Desk, and alerts `#leads-gurgaon-vip`.
4. What if the CRM is unavailable when a new lead arrives?
Zero-Loss Staging Buffer: Every lead is saved to Google Sheets before touching the CRM. If the CRM is offline, the system tries again after 1m, 5m, and 15m. An alert notifies operations so an advisor can call the client directly from the sheet. No lead is ever lost.
5. How do we prevent a failed workflow from processing the same lead twice?
Each lead gets a unique key: SHA256(phone + source + date). The system checks this key before creating records or sending messages. Retries only resume from the failed step, never duplicating contacts or messages.

Clean, readable logic that powers the workflow:

def process_incoming_lead(lead):
    # 1. Clean phone number and parse budget to numbers
    phone = clean_phone_number(lead["phone"])        # "+91 98765-43210" ➔ "9876543210"
    budget_inr = parse_budget(lead["budget"])        # "₹1.5 Cr" ➔ 15,000,000
    
    # 2. Safety copy in Google Sheets
    save_to_backup_sheet(lead)
    
    # 3. Check for duplicates in CRM
    existing_contact = find_contact_by_phone(phone)
    if existing_contact:
        add_note_to_contact(existing_contact.id, f"Repeat enquiry from {lead['source']}")
        notify_advisor(f"Repeat enquiry from {lead['name']}")
        return "TOUCHPOINT_MERGED"
    
    # 4. Check Priority (Gurgaon >= ₹1.5 Cr)
    is_vip = (lead["location"].lower() == "gurgaon") and (budget_inr >= 15_000_000)
    assigned_team = "Gurgaon Senior Advisory" if is_vip else "Standard Desk"
    sla = "15 Minutes" if is_vip else "2 Hours"
    
    # 5. Create new CRM contact and send alerts
    create_crm_contact(lead, is_vip, assigned_team, sla)
    send_slack_alert(channel="#leads-vip" if is_vip else "#leads-general", lead=lead)
    send_whatsapp_greeting(phone=phone, name=lead["name"])
    return "SUCCESS"

1. What does the automation do?

It acts as our 24/7 Digital Assistant: it captures leads from the website, WhatsApp, and ads automatically, merges duplicate enquiries so you don't call someone else's client, and immediately assigns luxury Gurgaon buyers (₹1.5 Cr+) to senior brokers.

2. How does the team use it daily?
